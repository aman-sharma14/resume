# 💼 Resume Portfolio Webpage  

## 📌 Overview  
A dynamic, interactive resume portfolio webpage built with HTML, CSS, and JavaScript. It features animated sections and a **Node.js-powered review system**, where users can leave feedback. Reviews are analyzed using **VADER Sentiment Analysis**, and only verified users can submit feedback via **email OTP authentication**.  

🔗 **[Live Demo (Frontend Only)](https://aman-sharma14.github.io/resume)**  
*Note: The demo is hosted on GitHub Pages, so backend functionalities (review system, OTP authentication) are not available.*  

## 🚀 Features  
- **Modern & Responsive Design** with animated sections for a smooth user experience.  
- **Review System** allowing users to post and sort feedback.  
- **Sentiment Analysis with VADER** for filtering and sorting reviews.  
- **OTP-based Email Authentication** using Nodemailer for secure interactions.  

## 🛠️ Tech Stack  
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Authentication:** Nodemailer (Email OTP Verification)  
- **Review System:** VADER Sentiment Analysis
